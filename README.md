
# Machine Learning Labs

A collection of Machine Learning laboratory exercises completed during my **6th Semester of Computer Engineering**. This repository contains practical implementations of core machine learning and deep learning concepts using **Python**, **Jupyter Notebook**, and popular data science libraries.

The labs cover the complete machine learning workflow, including data preprocessing, exploratory data analysis, visualization, supervised learning, unsupervised learning, and deep learning with Artificial Neural Networks (ANN) and Convolutional Neural Networks (CNN).

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/pandeyAsim/Machine-Learning-Labs.git
```

### Navigate to the Repository

```bash
cd Machine-Learning-Labs
```

### Install Required Libraries

```bash
pip install numpy pandas matplotlib scikit-learn tensorflow notebook
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```
